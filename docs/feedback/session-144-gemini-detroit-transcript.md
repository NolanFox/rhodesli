## Key insights for replicating this programmatically

1. **Provide rich biographical context up front.** Albert's full timeline (Minsk birth, 1906 arrival, 1910 NY, 1911 NY, **1917 Detroit**, 1919 return from France, marriage in Cincinnati, Dayton thereafter) was what let Gemini weight the Detroit hypothesis heavily. A short "Fox siblings, c.1918" prompt would likely not have produced the Detroit result.
2. **Include a reference portrait for age calibration.** Image 1 (wedding-era Albert) gave Gemini a visual anchor so it could say "slightly younger than the wedding photo -> 1912-1917" instead of guessing ±10 years. Our pipeline should pass the most confidently-dated same-subject reference photo when available.
3. **Describe the distinctive visual features in the prompt.** Gemini's reasoning hinged on identifying the structure as a **conservatory/greenhouse** (arched stone entry + attached glass wing + palm fronds). Prompting Gemini to describe the background architecture first, then identify it, mirrors this chain-of-thought.
4. **Ask for a ranked list of candidate buildings, not just one.** Turn 3 explicitly compared Dayton Soldiers' Home against Belle Isle. The Dayton elimination strengthened the Belle Isle identification. A programmatic prompt should ask Gemini to list 2-3 candidates with evidence, then pick the best.
5. **Request detail-level verification (fanlight mullion pattern, building junction, palm fronds).** This is the step that turned a plausible guess into "virtually certain." Our prompt should explicitly ask for the diagnostic architectural features that distinguish the chosen building from similar structures.
6. **Ask Gemini to cite archival photo sources.** Burton Historical Collection, HistoricDetroit, Wikipedia. This gives us verifiable provenance and lets us reuse image URLs for the UI.
7. **Exploit the architect's name.** Albert Kahn opened Belle Isle Conservatory in 1904 — Gemini used that as a temporal plausibility check. For any identified building, our pipeline should capture architect + opening year and use it to validate against the photo's date estimate.
8. **Three-round dialog pattern works well.**
   - Round 1: free-form estimate + building description (Gemini identifies conservatory features).
   - Round 2: commit to a specific building (Gemini picks Belle Isle).
   - Round 3: deep verification + pinpoint camera position (Gemini produces the definitive answer).
   This can be flattened into a single structured prompt with three labeled sections to save API calls.
