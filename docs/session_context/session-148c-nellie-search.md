## Methodology Learnings (for future feature development)
1. **Photo context is king:** Corsages, boutonnieres, seating position tell you relationships before any face matching.
2. **Cross-photo consistency:** Same outfit across photos at same event = same person. Tracking clothing is a strong signal.
3. **Age estimation + family tree = powerful filter:** Of 20 candidate photos, only 3 had anyone old enough to be Nellie. This eliminates 85% immediately.
4. **Mother-daughter embedding distance NOT directly useful here:** The search was sorted by distance to Sherry, but Nellie only appeared in photos that ALSO contained Sherry. A better approach: search for ALL faces in the collection, filter by age, then check co-occurrence with Sherry.
5. **Event classification matters:** Knowing "this is a wedding" immediately tells you who SHOULD be there (parents, siblings, friends).
6. **Disambiguation is hard:** Two older women at the same wedding — context alone can't always distinguish mother-of-bride from mother-of-groom without additional evidence.
7. **Gemini API opportunity:** A model that can analyze clothing patterns, estimate ages, classify events, and compare faces across photos would automate most of this reasoning.
8. **GEDCOM integration value:** If we knew from GEDCOM that Nellie was born 1909 and the photo is from 1965, we could auto-estimate her expected age and filter accordingly.
