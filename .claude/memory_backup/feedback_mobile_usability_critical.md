Mobile usability is the #1 adoption blocker. User tried to demo to David (with uncle Charlie) and couldn't get links out fast enough on phone. Performance + mobile UX together make it unusable.

**Why:** The goal is other people besides Nolan can use the app. Mobile is how most people will access it (sharing links in family group chats).

**How to apply:** Every session should consider mobile impact. Performance and mobile responsiveness are existential — they trump new features. Test on mobile viewport before declaring anything shipped.
