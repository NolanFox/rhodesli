Antigravity is for visual/design work, not logic/data. Write prompts to files.

**Why:** Antigravity (Gemini-backed) overstated changes and modified identities.json during a debugging session. It lacks data integrity awareness.
**How to apply:** Use Antigravity only for CSS, layout, and design tasks. Never for data mutations, identity operations, or backend logic. Always write the prompt to a file first (not inline). See also reference_antigravity_invocation.md for invocation syntax.
