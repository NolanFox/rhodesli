When identifying unknown people in photo archives:

1. **Start with full-collection clustering**, not filtered-by-distance. Filtering by distance to a known person biases toward same-age/similar-looking faces and misses the target.

2. **Event context is the strongest signal** — corsage, boutonniere, aisle walk, dance partners, seating position. This trumps embedding distance.

3. **Embedding kinship distance is WEAK** — mother-daughter gap was only 0.09 (1.29 vs 1.38). Useful as tiebreaker, not primary signal.

4. **Cross-collection similarity is NOT useful for in-laws** — Al Fader (married into Fox family) showed zero resemblance to any Fox member.

5. **Name collisions in genealogical records are common** — always verify death/birth dates with primary sources (death certificates, cemetery records), not other Ancestry trees.

6. **Same person can split across multiple embedding clusters** — glasses on/off, angle, lighting cause intra-person distances of 0.58-1.40. Need visual confirmation across clusters.

7. **Use local Read tool for photo analysis**, not Chrome browser. Far more efficient and auditable.

**Why:** Session 148c spent significant time on wrong hypotheses due to: starting with wrong filter, trusting unverified genealogical data, and initially using Chrome instead of local files.

**How to apply:** Any future identification session should follow the structured investigation format in docs/session_context/session-148c-investigation.json.
